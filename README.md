# astrotrack: Characterising LEO Satellite RFI in Wide-Field Radio Astronomy

![CI](https://github.com/Gabriella8080/astrotrack/actions/workflows/CI.yml/badge.svg) ![License](https://img.shields.io/badge/license-BSD--3-blue)

## Overview

`astrotrack` is an open-source Python package for characterising potential Low Earth Orbit (LEO) satellite interference in wide-field radio astronomy observations. While interferometric arrays are able to spatially localise LEO satellite radiation, wide-beam radiometers like REACH (de Lera Acedo et al. 2022) integrate the total sky power into a frequency spectrum and therefore lack equivalent strategies for identifying satellite-generated contamination. To address this limitation, `astrotrack` provides tools for combining Two-Line Element (TLE) data with site-specific observational constraints to identify LEO satellite flyovers and investigate their potential association with radio frequency interference (RFI).

> **Accompanying Paper**: *'astrotrack: Characterising LEO Satellite Interference in Wide-Field Radio Astronomy'*, in preparation.

## Data Availability

Raw HDF5 files containing PSD observations used for comparison are proprietary to the REACH collaboration and are therefore not made publicly available. The publicly available 12,270 TLEs used in this work are provided in a [CSV file](data/TLE-catalogues/TLEs.txt) downloaded from [Space-Track](https://www.space-track.org) on 17:10:37 UTC 14 June 2025.


## `astrotrack` Installation

To install `astrotrack` from source, follow the instructions below:

```bash
conda env create -f environment.yml
conda activate astrotrack
pip install -e .
```

The package can then be imported using:

```bash
import astrotrack
```

`astrotrack` is recommended to be used with the provided Conda [environment](environment.yml).


## Quick Start

The below example demonstrates how to initialise `astrotrack` using a provided TLE catalogue along with user-defined observational constraints, the satellite constellation of interest, and a target date:

```python
from datetime import datetime
from astrotrack.preprocess import load_satellite_data

data = load_satellite_data(
    tle_file="LEO_TLE_file.txt",
    target_date=datetime(2025, 1, 18, 12, 25, 8),
    obs_len=3600, 
    traj_res=60,
    obs_lat=51.5,
    obs_lon=-0.1,
    R=2000,
    horizon_data="Horizon-Profile.csv", 
    satcon="STARLINK"
)
```

## Example Usage & Workflow

`astrotrack` is organised into five modules. A typical workflow begins with initialising and structuring satellite Two-Line Element (TLE) data for analysis, after which the subsequent modules derive orbital properties, Doppler behaviour with respect to a ground-based experiment, animations, and enable spectral associations.

<br>
<div align="center">
  <img src="docs/images/package-modules.png" width="600">
</div>
<br>

- [`preprocess`](): Loads and filters satellite TLE data provided by the user.
- [`satcon_properties`](): Filters, analyses, and visualises satellite trajectories as well as their metrics. 
- [`doppler_analysis`](): Evaluates Doppler shifts and detectability relative to a user-defined instrument's specifications.
- [`satcon_animate`](): Generates 3-D trajectory animations.
- [`psd_analysis`](): Visualises satellite flyover properties alongside measured PSD data coincidential with satellite flyovers.

A detailed overview of all five modules, their key functions, and example usage is provided in a supplementary [document](docs/examples/examples.md).


A [demonstration notebook](notebooks/astrotrack_demo/01_astrotrack_demo.ipynb) is also provided, and includes usage of an example [horizon profile](data/horizon-profiles/REACH-horizon.csv) from the REACH experiment as well as a [TLE catalogue](data/TLE-catalogues/TLEs.txt) compiled from [Space-Track](https://www.space-track.org). A [baseline horizon profile](data/horizon-profiles/baseline-horizon.csv) corresponding to an idealised flat horizon is additionally available to be used directly, or modified by the user to incorporate site-specific observational constraints.

## Testing \& Validation

`astrotrack` is validated using unit tests covering the package's functionalities from [TLE preprocessing](tests/preprocess_test.py), deriving [satellite properties](tests/satcon_properties_test.py), performing [Doppler Analysis](tests/doppler_analysis_test.py), and analysis with [PSD observations](tests/psd_analysis_test.py).

The entire test suite can be run using:
```bash
pytest
```
